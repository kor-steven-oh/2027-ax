# S.LSI AX Challenge 2027

**사업부의 난제, 우리의 도전.** 사업팀 리더가 올해 풀어야 할 난제를 공개하면, 소속 팀에 관계없이 구성원이 도전한다. 현업 담당자와 함께 AI 해결안을 검증하고 실제 업무에 적용하는 것이 프로그램의 목표다.

## 랜딩 페이지 기획안

첫 화면에서 행사 취지를 전달하고 ‘도전 과제 보기’로 연결한다. 난제 카드에는 출제 팀, 현업이 풀고 싶은 질문, 성공 기준, 필요한 역량과 제공할 지원을 담는다. 이후 참여 역할과 팀 구성, 데이터와 멘토 지원, 파일럿까지의 일정, 평가 원칙, 신청 방법을 안내한다. 기존 대화에서 나온 설계 검증 로그 분석 과제는 카드 구성을 설명하기 위한 예시다.

## 랜딩 페이지 히어로

[index.html](index.html)을 브라우저에서 열면 된다. HTML, CSS, JavaScript와 로컬 미디어 파일을 함께 둔다.

[10초 영상](ax-match-cut.mp4) · [영상 순서대로 50컷 보기](ax-hero-contact-sheet.jpg) · [전문 분야 사진 8장](ax-research-contact-sheet.jpg) · [전체 사진 72장](assets/ax/)

수학 칠판, 단백질 구조 시각화, 건축 단면도, 우주왕복선, 우주정거장, 전파망원경, 입자 검출기, 풍동 실험 컷을 기존 IT 컷 사이에 배치했다. [공통 AX 글자](assets/ax/wordmark.svg)는 분필, 소프트웨어 UI, 도면 표제란, 장비 표식 등 각 매체의 표현을 따른다. 사진은 캠페인을 위해 생성한 이미지다.

첫 8초는 30fps로 편집한 49컷이다. 마지막 2초에는 코엑스 광장을 모티프로 한 전광판이 나타난다. [전광판 코드](billboard.js)는 광장 사진의 LED 영역 안에 벽과 바닥, 돌출된 AX의 앞면과 옆면, 그림자를 그린다. 포인터나 터치로 시점을 움직일 수 있다. 키보드에서는 전광판에 포커스를 둔 뒤 방향키를 누른다. 영상의 엔딩에는 같은 코드로 그린 기본 시점이 들어간다.

웹은 기본 무음으로 한 번 재생한다. ‘소리 켜기’로 음향을 들을 수 있고 ‘전광판 보기’로 인트로를 건너뛸 수 있다. 기기에서 동작 줄이기를 선택하면 정지된 전광판으로 시작한다.
